# Desenvolvimento Web Full Stack — InterLink

Esta pasta reúne os artefatos da disciplina **Desenvolvimento Web Full Stack** referentes à **Entrega 1** do projeto **InterLink**, plataforma de organização e venda de ingressos para eventos que conecta **Organizadores**, **Fornecedores** de produtos/serviços e **Clientes**.

## 🌐 Site publicado

O site está implantado (deploy) no [Render](https://render.com) e pode ser acessado em:

➡️ **[https://projeto4-698c.onrender.com/](https://projeto4-698c.onrender.com/)**

> ⚠️ O Render pode levar alguns segundos para "acordar" o serviço caso ele esteja inativo há um tempo (plano gratuito), então a primeira carga pode demorar um pouco.

## 💻 Código-fonte

O código-fonte do frontend está disponível em [`src/entrega1/frontend`](../../../src/entrega1/frontend), incluindo o servidor Node (`servidor-estatico.js`) responsável por servir as páginas HTML/CSS/JS em produção.
